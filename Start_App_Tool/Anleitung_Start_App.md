## Voraussetzungen vor dem ersten Start:

Stelle sicher, dass Node.js und Docker Desktop auf deinem Computer installiert sind. 
Das Skript wird dich darauf hinweisen, falls etwas fehlt.


### Schritt 1: Desktop-Verknüpfung erstellen

Mache einen Doppelklick auf die Datei verknupfung_desktop.bat (bzw. das Skript zur Erstellung der Verknüpfung).

Es öffnet sich kurz ein schwarzes Fenster. 
Auf deinem Desktop wird nun automatisch eine neue Verknüpfung namens "Softwareprojekt" erstellt.


### Schritt 2: Das Projekt starten

Mache einen Doppelklick auf die neu erstellte Verknüpfung "Softwareprojekt" auf deinem Desktop.


Beim allersten Start dauert es etwas länger. Das Skript führt folgende Schritte automatisch im Hintergrund aus:

- Startet Docker (falls es noch nicht läuft).

- Lädt und startet die Datenbank.


Installiert die benötigten Pakete für das Backend und Frontend (dies passiert nur beim ersten Mal oder wenn Pakete fehlen).

Sobald alles geladen ist, öffnet sich dein Webbrowser automatisch mit der Anwendung. Lass das schwarze Konsolenfenster im Hintergrund offen, solange du das Programm nutzt
